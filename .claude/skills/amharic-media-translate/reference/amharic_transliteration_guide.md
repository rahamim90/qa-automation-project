# Amharic Phonetic Transliteration Guide

Amharic is written in the Ge'ez script (Fidel), an abugida: each base consonant
has 7 forms ("orders"), one per attached vowel. This guide gives a practical
phonetic mapping to Hebrew letters and to Latin letters — not a formal
academic transliteration standard, but consistent and readable for a general
audience. Apply it the same way every time so output doesn't vary run to run.

## The 7 vowel orders

Shown here with ለ (consonant *l*) as the example; the same vowel pattern
applies to every consonant row.

| Order | Ge'ez | Vowel sound | Latin | Hebrew |
|---|---|---|---|---|
| 1st | ለ | short "e"/schwa | le | לֶה |
| 2nd | ሉ | "oo" | lu | לוּ |
| 3rd | ሊ | "ee" | li | לִי |
| 4th | ላ | "ah" | la | לָה |
| 5th | ሌ | "ay" | le / lé | לֵיי |
| 6th | ል | bare consonant / very short "i" | l / li | ל |
| 7th | ሎ | "oh" | lo | לוֹ |

## Worked example

ሰላም (greeting):
- Ge'ez breakdown: ሰ (se) + ላ (la) + ም (m)
- Latin: **selam**
- Hebrew phonetic: **סֶלַאם**
- Meaning: "peace" / used as "hello"

አመሰግናለሁ (thank you):
- Latin: **ameseginalehu**
- Hebrew phonetic: **אמסגינאלהו**
- Meaning: "thank you" (formal/polite)

## Usage notes

- Transliterate for *sound*, not for spelling — the goal is that a Hebrew or
  English reader can approximate the pronunciation, not reconstruct the Ge'ez
  spelling.
- Gemination (doubled consonants) is common in Amharic but not always marked
  in casual romanization; only call it out if it changes meaning.
- When a word has a well-known conventional English spelling (e.g. place or
  personal names), prefer that over a strict phonetic rendering, and mention
  the phonetic version alongside it if they differ.
- If a segment is unclear or ambiguous, say so explicitly rather than
  guessing silently.
