# Output Template

Use this structure for every piece of Amharic source material (a video, a
YouTube link, or an image). If the source has natural segments (subtitles,
sentences, or Whisper timestamp segments), repeat the block per segment;
otherwise use one block for the whole text.

```
### [Segment N | 00:00–00:05]  (omit the timestamp part for images / untimed text)

**אמהרית (מקור):** <original Ge'ez-script text>

**תעתיק בעברית:** <Hebrew-letter phonetic transliteration>

**תעתיק באנגלית:** <Latin-letter phonetic transliteration>

**תרגום לעברית:** <full, natural, meaning-based Hebrew translation>

**Translation (English):** <full, natural, meaning-based English translation>

**הסבר:** <notes: idioms, cultural context, ambiguous words, anything a
literal translation would miss. Skip this line if there's nothing notable.>
```

After all segments, if the source was a video/audio file longer than a
sentence or two, add a short **summary** in both Hebrew and English of what
the overall clip is about.

Keep translations natural and idiomatic in the target language — not word-
for-word — while keeping the transliteration strictly phonetic so the reader
can sound out the original.
